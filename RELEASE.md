# luafemm 0.11.0-dev

Generic LuaTeX magnetic modelling through TikZ/PGF/PGFPlots, supporting plain
LuaTeX, LuaLaTeX and ConTeXt MkIV. This version includes coupled harmonic circuits,
complex linear permeability and insulated-sheet magnetic losses, with documented
phasor conventions, separate loss observables and worked examples.

The manual executes its LuaLaTeX examples directly from the displayed sources.
Runtime files use the engine-specific TDS layout and select one installation.
Native cache revision 13 requires recomputation of incompatible snapshots.
Scientific scope and measured validation are stated in the manual; full FEMM
parity and general nonlinear harmonic laws are not claimed.

Author and Current Maintainer: Christophe Jorssen <christophe.jorssen@gmail.com>.
Maintenance status: maintained. Original work: LPPL 1.3c or later. The separately
licensed FEMM catalogue retains its upstream notices; see LICENSES.md.

The package was vibe-coded with OpenAI Codex and the Astra-6 model, under
Christophe Jorssen's direction. Neither AI assistance nor publication certifies
scientific correctness; independent validation remains necessary.
