\begin{abstract}
Declare magnetic media on ordinary TikZ paths, solve a finite-element
problem (static, transient or supported harmonic, planar or axisymmetric) entirely in Lua, and draw oriented field lines or PGFPlots profiles.
Prescribed coplanar electric charges and classical charged bodies or ideal
capacitors additionally provide analytical fields, equipotentials and quantitative profiles.
Planar and axisymmetric electrostatic finite elements resolve finite electrodes, dielectric interfaces
and prescribed volume or surface charges with the same drawing interface.
Analytical line or axial point sources can also be combined with a regular
finite-element correction for scalar dielectrics and voltage conductors.
The same generic implementation works with plain LuaTeX, LuaLaTeX and
ConTeXt MkIV. This manual documents every supported public key, the numerical
conventions, and the limitations of the supported models.
\end{abstract}
\section*{How to read this manual}
Start with the first picture and the tutorials. The reference then follows
three tasks: declare the physical model, obtain fields and measurements, and
reuse solutions for operating-point or machine studies. File exchange,
numerical assumptions and limitations have their own part.

A shaded code/result pair runs the code printed beside or below its result.
Each worked case is independent; names may be reused in a later case.
A setup block defines the styles, dimensions or saved models explicitly used
by the following blocks in the same worked case. Short configuration extracts
state their required picture or axis context in the surrounding text. Complete
runnable documents are also supplied in \texttt{examples/}; the reference does
not repeat their loading preambles. The format appendix is the named exception:
it compares the three complete wrappers around one shared scene.
